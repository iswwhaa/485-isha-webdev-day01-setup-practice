##  How a Browser Loads a Webpage

When a user enters a website address in a browser, the browser uses DNS (Domain Name System) to find the server's IP address. It then sends a request to the server to get the webpage. The server sends back website files such as HTML, CSS, JavaScript, and images.

HTML provides the structure of the page, CSS controls its appearance, JavaScript adds interactive features, and images provide visual content. Finally, the browser processes these files and displays the webpage on the screen.
